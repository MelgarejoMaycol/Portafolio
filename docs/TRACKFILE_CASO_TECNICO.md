# TrackFile — Ficha técnica pública

**Tipo:** proyecto académico de grado en desarrollo de software.
**Área:** organización documental y procesos del sector transporte.
**Tecnologías:** Flutter, Dart, Java, Spring Boot y PostgreSQL.

## Problema abordado

La información sobre documentos, usuarios, vehículos, solicitudes y mantenimiento puede quedar repartida entre diferentes registros. El proyecto plantea una aplicación para consultar y organizar esas tareas desde flujos de trabajo definidos.

## Alcance funcional

- Organización y consulta de registros documentales.
- Gestión de usuarios y vehículos.
- Solicitudes, seguimiento de mantenimiento y avisos.
- Formularios y pantallas para consultar el estado de la información.

Estas descripciones indican el alcance del proyecto; no representan estadísticas de uso en producción.

## Interfaz y experiencia de usuario

El cliente se desarrolla con **Flutter y Dart**. Las pantallas se diseñan alrededor de las tareas frecuentes: consultar, registrar, actualizar y dar seguimiento. Se priorizan la navegación entendible, los formularios y el tratamiento de estados durante la interacción con los servicios.

## Arquitectura general

La interfaz consume servicios de una API basada en **Spring Boot**; los datos de aplicación se almacenan en **PostgreSQL**. Se separan la presentación de datos y la lógica de servidor para facilitar cambios y mantenimiento.
